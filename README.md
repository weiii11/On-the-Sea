# On the Sea

一个可以看海、听浪的小小空间。陪你放空发呆，也陪你安静学习。

海面缓缓起伏，偶尔几条飞鱼掠过。你可以停留在晴日、晨雾、霞光或傍晚，打开海声，让浪声和画面一起轻轻涨落。

## 打开这片海

下载仓库后，用 Chrome 或 Edge 双击打开根目录的 **`index.html`** 即可。它是完整的离线网页，无需安装依赖，也无需联网。

- 点击右上角切换光线，选择「柔波」或「粼光」。
- 拖动画面环顾海面，双击回到初始视角。
- 点击「海声」开启声音，用滑块调整音量。
- 支持暂停和全屏；停留片刻后，按钮会自动淡出。

建议在电脑上体验。页面会自动控制渲染分辨率，以兼顾画面与流畅度。浏览器需要支持 WebGL 2。

## 继续修改

`src/` 保存当前版本的源码和实际使用的 Three.js 依赖。修改后，在仓库目录运行：

```sh
python build.py
```

这会重新生成根目录的 `index.html`。构建只使用 Python 标准库，不需要额外安装软件包。

当前版本包含实时海面、飞鱼与水花、偶尔经过的海鸥、四种光照、空间晨雾、带轻缓涨落的合成海声，以及高分屏性能优化。

声音由网页实时合成；页面不需要外部图片、录音或网络服务。

## 第三方依赖

使用 Three.js 及其 Water、Sky 组件。Three.js 的 MIT 许可证见 [`src/vendor/THREE-LICENSE.txt`](src/vendor/THREE-LICENSE.txt)。
